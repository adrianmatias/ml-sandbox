# Python vs Scala 3 tooling for a defined-but-never-called function — brief

Verified **2026-09-15** from PyPI JSON, GitHub, and tool source; Scala claims reproduced with scala-cli 1.17.0 on Scala 3.9.0. Scala current release: **3.9.0, 2026-09-03** ([downloads](https://www.scala-lang.org/download/all.html)).

## 1. Dead code / unused-code detection in Python

- **vulture 2.16, 2026-03-25** ([PyPI](https://pypi.org/pypi/vulture/json)); 4,810★, last commit 2026-04-30, ~1 maintainer. Codes `V101`–`V107`, `V201`: attribute, class, function, import (`V104`/`F401`), property, method, variable (`V107`/`F841`), unreachable ([README](https://github.com/jendrikseipp/vulture/blob/main/README.md)). Confidence **100%** = function/method/class *argument* + unreachable; **90%** = import; **60%** = everything else. **Default `min_confidence` is 0, not 60** ([config.py](https://github.com/jendrikseipp/vulture/blob/main/vulture/config.py)) — with no flags every 60% item prints, the mechanical source of CI noise; `--min-confidence 100` restricts to imports/args/unreachable. Wiring: `--make-whitelist` (a Python module passed as an extra path), `[tool.vulture]` with `ignore_names`/`ignore_decorators`. Bundled whitelists are **stdlib-only (14 files) — none for django/flask/pydantic/click** ([dir](https://github.com/jendrikseipp/vulture/tree/main/vulture/whitelists)); Flask recipe = `--ignore-decorators "@app.route"`. **FP profile**: 51 issues match "false positive" (django 12, pytest 13, flask 8, pydantic 5, dataclass 5); no `false positive` label exists, and **no independent FP-rate measurement was found** ([competing-vendor figures only](https://skylos.dev/blog/dead-code-detection-oss-cleanup-prs)).
- **ruff 0.16.7, 2026-09-10**, 49,635★. Unused scope: **F401** unused-import, **F841** unused-variable, **F811** redefined-while-unused, **F842** unused-annotation, **RUF059** unused-unpacked-variable, **RUF100** unused-noqa — all default-on; **ARG001–005 are stable (since v0.0.168) but not default-on**. **No cross-module dead-code analysis**: maintainers confirm in the still-open [#872](https://github.com/astral-sh/ruff/issues/872) (2024-02-21) and [#16488](https://github.com/astral-sh/ruff/issues/16488) (2025-03-04). **Measured: ruff 0.16.3 on unused `_private_fn`, `_private_method`, `__dunder_method` → `--select F,ARG,RUF` = "All checks passed!"; `--select ALL` emitted only ANN202/D100/D101/CPY001/SLF001.** Ruff ships `PYI018`/`PYI046`/`PYI047`/`PYI049` (unused private TypeVar/Protocol/TypeAlias/TypedDict), default-on — **`.pyi` stubs only**.
- **Alternatives**: **pyflakes 3.4.0, 2025-06-20** — **single-file by design**: *"Pyflakes only examines the syntax tree of each file individually"* ([README](https://github.com/PyCQA/pyflakes/blob/main/README.rst)). **dead 2.1.0, 2025-02-08**, 401★ — **measured: reports all three of `_private_fn`, `_private_method`, `__dunder_method` as "never read"**; self-described *"wrote this in ~15 minutes on an airplane"*, FPs = interface implementations and metaclass magic. **unimport 1.4.0, 2026-06-02** detects *and rewrites*. **flake8-unused-arguments 0.0.14, 2025-10-27**. **pylint 4.0.8, 2026-08-29**: W0611/W0612/W0613/W0614. **coverage.py 7.16.1, 2026-09-13** — `report -m` lists *"line numbers … that weren't executed"*, but as a dead-code proxy it is **qualified**: `def foo():` *is* covered (executed at import) — *"It's the body of the functions that will be marked as not executed… not the def lines"* ([FAQ](https://coverage.readthedocs.io/en/latest/faq.html)). Function-level coverage shipped 7.5.0; **pytest-cov 7.1.0, 2026-03-21**. Newer: **dead-code-detector 0.5.0, 2026-03-31** (BFS reachability from entry points; *"overapproximates by design"*); **reaper-py 0.1.0, 2026-02-21** (Rust, 29 downloads).

**The exact gap — yes, but no single tool equals `-Wunused:privates`:**

| Tool | module `_fn` | method `_m` | method `__m` | enabled |
|---|---|---|---|---|
| vulture 2.16 | ✅ V103 @60% | ✅ V106 @60% | ✅ V106 @60% | on (min-conf 0) |
| dead 2.1.0 | ✅ | ✅ | ✅ | on |
| pyright `reportUnusedFunction` | ✅ | ❌ | ✅ | **`"none"` = OFF** |
| basedpyright 1.40.1 | ✅ | ❌ | ✅ | **`"warning"` = ON** |
| pylint W0238 | ❌ | ❌ | ✅ | on |
| ruff 0.16.7 | ❌ | ❌ | ❌ | — |

- **pylint W0238 `unused-private-member` exists** ([docs](https://pylint.readthedocs.io/en/latest/user_guide/messages/warning/unused-private-member.html)) but "private" means **≥2 leading underscores** (`is_attr_private` = `^_{2,10}.*[^_]+_?$`) and it is **class-scope only**; measured, it flagged `__dunder_method` but neither `_private_method` nor module-level `_private_fn`.
- **pyright's `reportUnusedFunction` is the closest analogue** yet its doc wording misleads: `_isSymbolPrivate` returns `!isClassScope` for single-underscore names, so **`_method` inside a class is never reported** ([checker.ts](https://github.com/microsoft/pyright/blob/main/packages/pyright-internal/src/analyzer/checker.ts)), and decorated functions are skipped by an explicit early return. basedpyright 1.40.1 defaults to `typeCheckingMode = "recommended"` (all rules warning/error, `failOnWarnings` true) and adds `reportUnusedParameter`, which pyright lacks ([docs](https://github.com/DetachHead/basedpyright/blob/main/docs/configuration/config-files.md)).

## 2. Scala 3's native equivalent

- **Choices in 3.9.0** ([ScalaSettings.scala @3.9.0](https://github.com/scala/scala3/blob/3.9.0/compiler/src/dotty/tools/dotc/config/ScalaSettings.scala)): `nowarn`, `all`, `imports`, `privates` ("a private member is unused"), `locals`, `explicits`, `implicits`, `params` (= explicits + implicits), `patvars`, `linted` (= imports + privates + locals + implicits). `inlined` is a commented-out TODO; default `Nil`. Family introduced in **3.3.0** ([blog, 2023-05-30](https://www.scala-lang.org/blog/2023/05/30/scala-3.3.0-released.html)).
- **Two corrections to the common assumption.** (1) **`synthetics` does not exist in Scala 3** — Scala 2.13-only; absent from every 3.3.0–3.9.0 settings source. (2) **`-Wunused:all` is not a full expansion**: `allOr` covers imports/privates/locals/explicits/implicits/patvars, but **`nowarn` is read via `isChoiceSet("nowarn")` directly, so `-Wunused:all` does NOT enable it**, nor `params` as a group, nor `strict-no-implicit-warn` — verified empirically (`-Wunused:nowarn` alone fired the `@nowarn`-didn't-suppress warning; `all` did not). **`explicits` means explicit (non-`using`) parameters, not `given`s.**
- **`-Xfatal-warnings` is a deprecated alias of `-Werror`** (`SettingAlias("-Xfatal-warnings", Deprecation())`). **There is no dedicated official `-Wunused` docs page** (`.../compiler-options/wunused.html` → 404); the only official page is the LLM-assisted [E198: Unused Symbol](https://docs.scala-lang.org/scala3/reference/error-codes/E198.html). **`-Xlint` is a deprecated boolean** (`since = "3.5.0"`, "Superseded by `-Wshadow`", `ignoreInvalidArgs = true`), so `-Xlint:unused` is **accepted and ignored** — no subset relationship with `-Wunused`. `-Wall` (3.5.2) is a separate boolean `allOr` ORs in, *not* an alias for `-Wunused:all`.
- **Scala does NOT report unused public members — verified both ways.** `isEffectivelyPrivate` = `sym.is(Private, butNot = ParamAccessor) || (owner.isAnonymousClass && !isEffectivelyOverride)`; **`Protected` and `private[pkg]` never enter `checkPrivate`**, and no unused-public-member message exists ([CheckUnused.scala @3.9.0](https://raw.githubusercontent.com/scala/scala3/3.9.0/compiler/src/dotty/tools/dotc/transform/CheckUnused.scala)). Empirically: a never-called top-level `def`, a `protected def`, and a `private[t] def` produced **zero** warnings; only `private` class/anonymous-class members warned. **So both languages miss the unused-*public* case.**
- **Two further limits.** **Transitive dead code is not caught**: with `private def rootDead` and `private def onlyCalledByDead = rootDead()`, only `onlyCalledByDead` was reported — no reachability closure. The **direct** case *does* become a build failure under `-Wunused:all -Werror`, verified live (E198 → "No warnings can be incurred under -Werror"). So Scala wins on unused private members generally, but Python's vulture/dead cover the same class — including a **single**-underscore private *method*, which neither pylint's W0238 nor any Python type checker can flag.
- **FP suppression built in**: `checkPrivate` exonerates `isSerializationSupport`, `CaseAccessor`, `BodyRetainerName`, and `@unused`/`nowarn` symbols; `checkParam` exempts `_`-prefixed names, `@unused`, singletons, and erased params. Known FP/perf classes: `Selectable` ([#23323](https://github.com/scala/scala3/issues/23323)), private inner class ([#24326](https://github.com/scala/scala3/issues/24326), open), compile-time cost ([#19671](https://github.com/scala/scala3/issues/19671)).
- **Complements.** **Scalafix** 873★, **v0.14.9 (2026-09-13)**; `RemoveUnused` **consumes the compiler's own unused diagnostics from SemanticDB**, so it *requires* `-Wunused`/`-Wall` enabled **and** `-Xfatal-warnings` disabled (or `-Wconf:cat=unused:info`); `--check` fails on a would-be diff ([docs](https://raw.githubusercontent.com/scalacenter/scalafix/main/docs/rules/RemoveUnused.md)). **WartRemover** 1,103★, **v3.6.1 (2026-07-01)** — **no unused-symbol warts at all**. **sbt-tpolecat** 410★, **v0.5.7 (2026-06-25)**, via [typelevel/scalac-options](https://github.com/typelevel/scalac-options): sets the family **individually, not via `all`**, and **`-Xfatal-warnings` is added only in CiMode/ReleaseMode, not the default DevMode**. **scalafmt does nothing here.** **Scoverage** (439★, v2.5.2) reports *uncovered*, not unreachable, code; **Metals** has no dead-code detection.

## 3. Type checkers: state, conformance, speed

Versions/dates: **mypy 2.3.1** (2026-08-15, community, 20,641★); **pyright 1.1.414** (09-10, Microsoft, 15,643★); **basedpyright 1.40.1** (09-10, DetachHead, 3,592★); **pyrefly 1.3.1** (09-15, Meta, 6,966★); **ty 0.0.81** (09-15, Astral, 19,692★); **zuban 0.9.3** (09-02, commercial); **pyre-check 0.10.0** (08-06, Meta); **pytype 2024.10.11** — **stale since Oct 2024**.

- **Unused-code support is nearly absent from the new checkers.** mypy has only `--warn-unused-ignores`/`-configs`/`--warn-unreachable` (all default OFF) and **no unused-function check**. pyrefly has only `unused-coroutine`/`-call-result`/`-ignore`/`-type-ignore`; ty has only `unused-awaitable`/`-ignore-comment`/`-type-ignore-comment`. **Only pyright/basedpyright expose `reportUnusedImport/Class/Function/Variable`** (default `"none"`).
- **Conformance — live dashboard** ([results.html](https://github.com/python/typing/blob/main/conformance/results/results.html), 145 tests, fetched 2026-09-15): **pycroscope 0.5.0 — 144.5/145 (99.7%)**; **pyright 1.1.410 — 140.5 (96.9%)**; **zuban 0.9.2 — 138 (95.2%)**; **pyrefly 1.3.0-dev.1 — 136 (93.8%)**; **mypy 2.1.0 — 135.5 (93.4%)**; **ty 0.0.81 — 108.5 (74.8%)**. Against the [Pyrefly snapshot of 2026-03-10](https://pyrefly.org/blog/typing-conformance-comparison/) (pyright 97.8, zuban 96.4, pyrefly 87.8, mypy 58.3, ty 53.2) the shift is large: **mypy moved 58.3% → 93.4% in five months.**
- **Speed** ([Pyrefly benchmark, 2026-04-10](https://pyrefly.org/blog/speed-and-memory-comparison/), MacBook M4, no caching, 53 packages): scipy — pyright **151.3 s** / pyrefly **4.8 s** / ty **2.8 s**; pandas 144.4 / 1.9 / 1.5; numpy 70.9 / 4.8 / **30.6**. Meta reports Instagram's 20 M-line codebase at ~30 s under pyrefly. Cross-check ([pydevtools, 2026-04-29](https://pydevtools.com/blog/ty-and-pyrefly-find-different-bugs.md)): on rich (~38 k lines) ty 0.0.32 at 0.18 s raised 49 errors vs pyrefly 0.62.0 at 0.32 s raising 20, roughly half shared — **complementary, not equivalent**.
- **ty** has **no strictness mode and no missing-annotation diagnostic** in its ~130-rule set (only `strict-equality-semantics`, `strict-generic-narrowing`); it adds `missing-direct-dependency`, **preview since 0.0.76, default `ignore`**.

## 5. Evidence on tool efficacy

- **Type checkers on real type bugs**: mypy/pyright/pytype detect **29/40 (72.5%)** after annotation vs **14/40 (35%)** before, over 10 Python projects (ICPC 2023, [paper](https://conf.researchr.org/details/icpc-2023/icpc-2023-research/8/How-Well-Static-Type-Checkers-Work-with-Gradual-Typing-A-Case-Study-on-Python)).
- **Ecosystem scale**: **70%** of 13,751 client repos have ≥1 third-party-API type error (mean 84, median 14); benefits appear only at **≥90% library annotation coverage**; only **10%** of 566,877 library-client pairs sit in the ideal high-coverage+checker quadrant (ASE 2026, [PDF](https://sanadlab.org/assets/pdf/AsareASE2026.pdf)).
- **Agent loops — the strongest 2026 measurement found.** Meta/Pyrefly on SWE-bench Verified (low coverage) and internal MetaSWEBench (high coverage): *"type checking helped the agent only when the code base was well typed… the success rate increased from about 80% to 84%"*. On low-coverage code: *"no meaningful impact"* — errors *"distracted the agent and took it off course"*, and it *"would typically solve for type checker cleanliness in adjacent code rather than solving the task"*. Feedback must arrive **on every edit as a separate conversation step** (once at the end → *"the models never went back to fix anything"*); *"type checked X files and found zero errors"* worked as a *"great external reflection cue"* ([PyCon US 2026, 2026-06-09](https://pyrefly.org/blog/type-checking-agentic-workflows/); vendor-authored, unreplicated).
- **Security scanners on real Python CVEs** (108 CVEs / 62 projects; ICSE 2026 *Distinguished Paper*, re-tabulated by [PyFlow](https://arxiv.org/html/2608.07026v1)): Semgrep **65.7% P / 40.7% R**; CodeQL 72.3/31.8; Bandit 60.0/27.8; Dlint 72.5/26.9; Snyk 80.0/11.9; Pysa 0/0. **No baseline exceeded 40.7% recall.**
- **Suppression and tolerance**: **7,357 suppressions across 46 Python projects; 50.8% affect no warning and are "practically useless"**, rising monotonically (FSE 2025, [paper](https://conf.researchr.org/details/fse-2025/fse-2025-research-papers/42/An-Empirical-Study-of-Suppressed-Static-Analysis-Warnings)). NIST SATE V/VI: only **8–30%** of warnings were security-relevant; developers tolerate **≤~10%** FPs in code review (Sadowski et al., CACM 2018).
- **Stacking**: ≥**24% (74/304)** of PMD rules duplicate other tools'; **51.5%** of SonarQube–PMD and **45.4%** of SpotBugs–ErrorProne warned lines overlap (ICPC 2022, [PDF](https://www.eecs.yorku.ca/~wangsong/papers/icpc2022.pdf)). Relatedly, one Polars function needed **four different ignore comments in 7 lines** to satisfy four checkers, while all five agreed on the same test code ([Pyrefly/Quansight, 2026-06-03](https://pyrefly.org/blog/too-many-type-checkers/)).
- **Mutation testing**: Google ran 17 M+ mutants over 760,000 changes; **85% of initially reported mutants were judged unproductive** before heuristics raised productivity to 89%; median 2 live mutants per changelist, p99 = 43 (IEEE TSE 2021, [arXiv:2102.11378](https://ar5iv.labs.arxiv.org/html/2102.11378)).
- **Dead code**: **25% of methods dead** in a commercial .NET app; **30% of a PHP subsystem's LOC removed**; **7.6% of modifications affected dead methods, 48% unnecessarily** (IEEE TSE 2018, [restated](https://core.ac.uk/download/643634694.pdf)). Google's Sensenmann removed **~5% of the C++ codebase** ([2023-04-28](https://testing.googleblog.com/2023/04/sensenmann-code-deletion-at-scale.html)).
- **AI-generated code**: **24.17% of agent-modified Python files introduce new Pylint issues; 4.7% introduce new Bandit findings; 73.5% of those PRs were merged anyway** ([arXiv:2605.21453](https://ar5iv.labs.arxiv.org/html/2605.21453)).

## CONFIDENCE

**Well-evidenced (primary sources, 2026-09-15)**
- Every version, star count, and release date: PyPI JSON, GitHub releases/repo API, or the tool's own source tree.
- **Scala §2**: the choice list, `allOr` vs `isChoiceSet` semantics, the `-Xfatal-warnings` alias, the `isEffectivelyPrivate` guard, and the absence of `synthetics` — read from scala3 at tag 3.9.0 **and reproduced by compiling with scala-cli 1.17.0 on Scala 3.9.0** (direct private case → compile error; public/protected/`private[t]` → silent; transitive dead → silent; `-Wunused:all` did not fire `nowarn`).
- **pylint W0238** scope: source plus execution (class-scope, `__`-only). **pyright `reportUnusedFunction`** scope: the `isProtectedName`/`_isSymbolPrivate` path (`return !isClassScope`) plus a measured run; decorated functions are skipped by an explicit early return.
- **ruff detects no unused function or method**: measured (`--select ALL` produced none), corroborated by two maintainer statements.
- **vulture's default `min_confidence = 0`** and its 60/90/100 table: source plus a run with no flags.
- **Semgrep rule composition** (151 rules in `p/python` = 138 security + 13 audit; free, unauthenticated; CE single-function-only): fetched from `semgrep.dev/c/p/python` and the CE docs.
- **Conformance figures**: parsed from the live `results.html` footer, column order from the same file's header.
- **Meta agent-loop experiment**: primary transcript with stated setup. Vendor-authored, self-reported, **no replication found**.
- The **"Scala catches it, Python doesn't"** framing is well-evidenced **only for the direct private case** — the one form reproduced end-to-end in both languages.

**Thin or absent**
- **No primary maintainer statement** that Scala excludes public members *because they are API* — inferred from the E198 list plus the `isEffectivelyPrivate` guard. The code is solid; the rationale is not quoted.
